# ⏳ TimeFlow — Desktop Time Progress Widget

**TimeFlow** คือโปรแกรม Desktop Widget สไตล์มินิมอล (Frosted Glass / Glassmorphism) สำหรับ Windows ที่ลอยอยู่บนหน้าจอเดสก์ท็อป สามารถคลิกลากย้ายตำแหน่งได้อิสระ เพื่อเตือนสติและแสดงความคืบหน้าของเวลาแบบ Real-time

---

## 🌟 ฟีเจอร์เด่น (Key Features)

- 🪟 **Floating Frameless & Transparent Window**: หน้าต่างกระจกใสไร้กรอบ ผสานกลมกลืนกับ Wallpaper บน Desktop
- 🖱️ **Draggable Anywhere**: คลิกลากบริเวณแถบด้านบนหรือการ์ดเพื่อย้ายไปวางมุมไหนของหน้าจอก็ได้
- 📌 **Always on Top (Pin)**: ปุ่มหมุดตรึงหน้าต่างให้อยู่เหนือโปรแกรมอื่น หรือปล่อยให้อยู่ติดพื้นหลัง Desktop
- ➖ **Mini Capsule Mode**: ปุ่มย่อขนาดเป็นแถบแคปซูลเล็กๆ ประหยัดพื้นที่ และกดขยายกลับมาได้
- 📊 **Real-time Time Progress**:
  - 🌍 **ปี 2026**: แสดง % เวลาที่ผ่านไปแล้วของปี พร้อมจำนวนวันที่เหลือ
  - 🗓️ **เดือนนี้**: แสดง % ของเดือน และจำนวนวันที่เหลือ
  - 📅 **สัปดาห์นี้**: แสดง % ของสัปดาห์ (จันทร์ - อาทิตย์)
  - ☀️ **วันนี้ (Today)**: แสดง % ของวัน พร้อมชั่วโมง/นาทีที่เหลือ
- 🧬 **Life in Weeks Matrix**: ตารางจุด 1000 สัปดาห์ของชีวิต คำนวณจากวันเกิดจริง
- 🎨 **Theme & Customization**: สลับสไตล์กระจกได้ 4 แบบ (Frosted Dark, Light, Sage Green, Midnight) พร้อมตัวปรับระดับความโปร่งแสง

---

## 🚀 วิธีเปิดใช้งาน

1. ดับเบิลคลิกที่ไฟล์ **`run.bat`** (หน้าต่าง Widget จะลอยขึ้นมาบนหน้าจอ Desktop ทันที)
2. หรือเปิดไฟล์ **`index.html`** ผ่านเว็บเบราว์เซอร์
